## 2024-04-17 - [Accessible Toggles]
**Learning:** Interactive toggles (like payment status) implemented as `<div>` elements are inaccessible to keyboard users and screen readers. Using a generic `role="button"` is okay, but `role="switch"` combined with `aria-checked={boolean}` is much better for communicating precise, semantically accurate binary states to screen readers. Focus styles must also be explicitly added using Tailwind's `focus-visible:` utilities.
**Action:** When implementing or refactoring toggle interactions, always use a `<button type="button" role="switch">` with `aria-checked`, handle `disabled={isPending}` states during async actions, and ensure clear `focus-visible` outlines. Decorative inner elements indicating state (like colored dots) should have `aria-hidden="true"`.
