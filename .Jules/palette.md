## 2025-02-18 - [Add Patient Dialog A11y & Visual Feedback]
**Learning:** `shadcn/ui` `Label` components (which wrap Radix UI `Label`) don't implicitly wrap `Input` components in this codebase. They are rendered as siblings, which means explicit `htmlFor` (on `Label`) and `id` (on `Input`) attributes are strictly required for screen reader accessibility and click-to-focus behavior. Additionally, form validation error messages lacked `role="alert"`, delaying their announcement to assistive technologies.
**Action:** When working with forms using `shadcn/ui`, always explicitly bind `Label` and `Input` components using `htmlFor`/`id`. Ensure all transient error messages use `role="alert"`. When adding loading states to `Button` components, leverage existing project icons like `Loader2` from `lucide-react` with `animate-spin`.
